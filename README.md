#YT-Downloader
A simple Python YouTube downloader using yt-dlp and FFmpeg.
Features
- Download videos in Full HD (1080p).
- Download videos in 360p.
- Download audio in MP3.
- Automatically installs FFmpeg and yt-dlp using Winget.
#Requirements
- Windows
- Python 3
- Winget
#Usage
Run the program:

python YT-Downloader.py

Choose your preferred format, paste the YouTube URL, and let it download!
#Download Location
Files are saved in the terminal's current working directory.

Note: This is usually the program's folder when launched from there, but not always. If you paste the code directly into a terminal, downloads are saved in the terminal's current directory.
